## 范围

- 左侧：项目、新建任务、任务搜索与紧凑列表、当前任务阶段、底部需求输入与真实可用的模型模式；资料/Skills/设置保留为底部辅助入口。
- 右侧：当前任务标题与状态、真实执行记录时间线、类型筛选、详情展开、Spec编辑审批、受控运行和产物查看。工作台采用全屏双区、各区域独立滚动。
- 任务沿用现有Spec主键，状态由该任务最新运行与审批结果推导，不引入另一套可编辑任务状态。新建提交明确创建新任务，不伪装成已有任务的聊天续写。
- 执行接口只读取当前项目与当前任务关联的审计、运行、JSONL及验证证据。没有真实记录时展示空状态；不生成虚假工具调用、推理或Git上传结果。
- 保留未保存草稿、版本/Hash门禁、资料版本、项目隔离与已有运行数据。无需数据库结构迁移。
- 桌面左栏约320px，执行区占满剩余空间；小屏任务栏改为可开关抽屉，支持键盘和Escape。

## 验收

1. 在独立临时数据根目录创建两个任务，点击左侧切换后右侧规格与执行记录正确隔离。
2. 搜索任务、输入新任务、编辑保存、明确审批、运行成功/失败场景、查看真实产物均可操作。
3. 筛选日志及展开详情不改变任务真实状态；刷新后保留项目与任务选择。
4. 1366/1920/390宽度无页面级横向溢出，桌面主页面不产生整页滚动；侧栏长列表、长标题和执行长文本仍可操作。
5. 沿用正式API、关系存储、来源及审批测试，真实浏览器检查控制台与布局。

当前仍为明确标记的受控沙箱；此次不新增真实业务Git推送或应用预览能力。

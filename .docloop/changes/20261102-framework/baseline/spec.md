## 模块与数据流

- `src/docloop/`：数据契约、需求控制器、执行控制器、可靠性控制器、LangGraph 图、持久化、CLI、适配器接口。
- `.docloop/`：按原文目录组织项目配置、角色、Rules、Skills、Profile 和运行产物。
- `tests/`：门禁、角色权限、基线校验、重试/预算/熔断、证据覆盖、恢复与归档测试。
- 输入 Markdown → 来源索引 → Spec 草稿 → 等待明确审批 → Hash 基线 → 工作区与计划接口 → 实现 → 独立验证 → 审查 → 归档。
- 实现/验证/审查使用不同角色接口。离线演示使用确定性适配器，不宣称真实模型执行或独立人工验收。
- 模型、MCP/CLI、浏览器、Worktree、上游 Superpowers 作为适配器边界。未配置的真实能力返回 blocked/not_run，不伪造成功。
- Superpowers 运行时必须检查锁定版本。首轮不猜测 SHA，也不将未安装的上游 Skills 标记为已加载。
